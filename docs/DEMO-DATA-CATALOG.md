## Prohibited demo use

Never place a fictional name, quote, number, signature, endorsement, legal conclusion, government identifier, audit result, custody signer, or proof status in a position where a normal reader could reasonably mistake it for real evidence.

## Replacement protocol

1. Keep the DEMO DATA label while drafting.
2. Obtain direct authorization or evidence.
3. Replace the record with the real scope, date, source, and owner.
4. Run disclosure and release checks.
5. Remove the demo label only when the evidence record is complete.
6. Preserve the old demo artifact only in internal development notes, not public evidence.
